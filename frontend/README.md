# PitWall frontend

The React + Vite site for PitWall, deployed on Vercel. It talks to the FastAPI backend at `VITE_API_URL` (falls back to `http://127.0.0.1:8000` for local runs).

Run it: `npm install`, then `npm run dev`. Build it: `npm run build`.

How the pages and components fit together: [Frontend notes](../Fantasy%20Predictor/Frontend.md).
